# MCCI XP level color

A Fabric mod which changes the color of the XP level text when on the [MCC Island](https://mccisland.net) server.

## Dependencies

The mod requires [Fabric API](https://modrinth.com/mod/fabric-api) and [Yet Another Config Lib](https://modrinth.com/mod/yacl) to be installed in order to work.

## Credits

The method of checking if the user is on MCCI was taken from [MCC Island Tooltips](https://github.com/derNiklaas/MCC-Island-Tooltips) by derNiklaas.
